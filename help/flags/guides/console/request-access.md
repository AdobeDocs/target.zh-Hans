# 请求访问 {#request-access}

在团队级别管理对标志的访问。 要使用标志，您需要添加到具有相应角色的团队中。

## 先决条件 {#prerequisites}

在请求访问之前，请确认以下内容：

* 你知道该加入哪一队。 与您的产品或工程主管核实，确定您的团队及其管理员。
* 您知道您需要访问哪个沙盒。

## 请求访问 {#request-steps}

请联系您的Adobe代表以请求获取访问权限。

## 可用的角色 {#roles}

分配给您的角色决定了您可以在控制台中执行的操作。 如果您不确定要请求哪个角色，请联系您的管理员。

| 角色 | 描述 |
| --- | --- |
| **管理员** | 控制台的完全访问权限。 可以管理应用程序。 |
| **产品版本所有者** | 可以创建和管理功能标志和功能组，并将功能发布给外部用户。 |

## 授予访问权限后 {#after-access}

您的请求获得批准后，请在Adobe Target中打开标记，并验证您的应用程序是否可见。 有关后续步骤，请参阅Adobe Target中的[访问标志](log-in-to-the-console.md)。

## 需要帮助？ {#need-help}

如果您不确定要加入哪个团队，或者您的项目尚无团队，请联系贵组织的标记管理员。
