# 创建您的第一个功能标记 {#create-feature-flag}

## 先决条件 {#prerequisites}

在创建功能标记之前，请完成以下操作：

* 您有权访问标记控制台 — 请参阅[登录到控制台](../console/log-in-to-the-console.md)
* 您的应用程序已载入 — 请参阅[将应用程序载入](../applications/onboard-your-application.md)
* 您具有&#x200B;**产品版本所有者**&#x200B;角色

## 第1步：创建功能标记 {#create}

要创建新功能标记，请在控制台中执行以下步骤：

1. 登录到&#x200B;**标记控制台**，转到左侧面板，然后选择&#x200B;**功能标记**。
1. 从&#x200B;**应用程序**&#x200B;下拉列表中选择您的应用程序。
1. 选择&#x200B;**新功能标志**。
1. 填写表单字段：

   | 字段 | 描述 |
   | --- | --- |
   | **名称** | 功能标志的显示标签。 未在代码中使用。 |
   | **键** * | 代码中用于评估标记的标识符。 创建后无法更改。 |
   | **描述** | 用于文档用途的可选描述。 |
   | **元数据** | 可选。 最多1,024个字符。 此字段用于要与标记关联的任何其他元数据。 |
   | **标记** | 用于文档用途的可选标记。 |
   | **标识** * | 评估标记的标识（例如，ECID）。 这是功能请求中传递的标识。 |
   | **转出百分比** | 您定义的受众中使用此功能的百分比。 默认为100%。 请参阅[设置功能以逐步推出](set-feature-gradual-rollout.md)。 |

   标有*的字段为必填字段。

>[!IMPORTANT]
>
>**Key**&#x200B;是代码中使用的标识符，在创建后无法更改。 键&#x200B;**不能包含空格**，并且是&#x200B;**区分大小写的**。 **Name**&#x200B;仅是显示标签，不在代码中使用；两者是独立的（名称未转换为键）。 在键字段中输入空格会产生错误： _“功能键的值无效。”_

1. （可选）添加受众标准（请参阅步骤2）。
1. 保存功能标志设置。

## 步骤2：添加受众标准 {#audience}

受众标准可控制哪些用户会看到该功能。 您可以定位具有&#x200B;**上下文属性**&#x200B;的用户 — 您的网站或应用程序在功能请求中发送的值（例如`locale`或`platform`）。 将它们与&#x200B;**AND**、**OR**&#x200B;和&#x200B;**NOT**&#x200B;合并。 请参阅[在受众规则中使用上下文](../audience/using-context-in-audience-rules.md)。

要添加受众条件，请在创建或编辑功能标志时转到&#x200B;**受众**&#x200B;选项卡。
