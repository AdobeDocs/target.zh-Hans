# 经典版推荐文档 {#recs-classic-documentation}

>[!BEGINSHADEBOX]

**在此页面上：**&#x200B;查找旧版[!DNL Recommendations]产品[!DNL Recommendations Classic]的文档。

>[!ENDSHADEBOX]

[!DNL Recommendations Classic]会根据网站上以前的用户活动自动显示客户可能感兴趣的产品或内容。 这些推荐有助于将客户导向到在其他情况下他们可能不知道的项目，从而提高网站产生的销售额。

>[!IMPORTANT]
>
>[!DNL Recommendations Classic] 是一个旧版产品，不再许可给新客户。 为了获得最佳的[!DNL Recommendations]体验，请升级到[Adobe Target Premium](/help/main/c-intro/intro.md)中提供的[!DNL Recommendations]活动。

要在[!DNL Target Premium]中的[!DNL Recommendations Classic]和[!DNL Recommendations]个活动之间进行选择，请参阅Target Premium中的[Recommendations Classic与Recommendations活动的对比](/help/main/c-recommendations/c-recommendations-faq/recommendations-classic-versus-recommendations-activities-target-premium.md)。

可以采用PDF格式下载[Adobe Recommendations Classic](/help/main/assets/adobe-recommendations-classic.pdf)的文档。
