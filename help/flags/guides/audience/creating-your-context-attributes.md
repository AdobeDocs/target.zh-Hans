# 创建上下文属性 {#creating-your-context-attributes}

上下文属性是描述用户、会话或应用程序上下文的自定义数据字段（例如，订阅层、应用程序版本或区域）。 使用上下文属性定义功能标志的受众条件。

上下文组将相关的上下文属性组织到逻辑层次结构中。 使用上下文组使属性在功能配置期间更易于查找和管理。

| 术语 | 描述 | 使用位置 |
| --- | --- | --- |
| **上下文属性** | 具有数据类型和可选预定义值的命名字段。 | 受众标准，功能配置 |
| **上下文组** | 组织相关上下文属性的类别。 | 创建特征时的上下文选择 |
| **UI标签** | 用户界面中显示的显示名称。 | 受众标准和管理页面 |
| **ID** | 唯一的技术标识符。 | 应用程序请求 |
| **预定义值** | 包含显示标签的允许值的可选列表。 | 下拉列表和受众规则生成器 |

## 先决条件 {#prerequisites}

在管理上下文属性和上下文组之前，请完成以下操作：

* 您可以在正确的沙盒中访问&#x200B;**标记控制台**。
* 您具有创建和管理上下文属性和上下文组所需的&#x200B;**管理员**&#x200B;角色。

## 导航到上下文属性 {#navigate}

1. 登录到&#x200B;**标记控制台**。
1. 在左侧导航中的&#x200B;**功能板**&#x200B;下，选择&#x200B;**上下文属性**。

您现在位于&#x200B;**上下文属性**&#x200B;页面。 此页用于创建上下文组和上下文属性。

## 创建上下文组 {#create-group}

每个上下文属性都必须属于一个组。

1. 在左侧导航中的&#x200B;**功能板**&#x200B;下，选择&#x200B;**上下文属性**。
1. 在&#x200B;**我的上下文属性**&#x200B;选项卡上，选择&#x200B;**添加组**。
1. 完成必填字段。
1. 选择&#x200B;**创建**。

### 组字段 {#group-fields}

| 字段 | 描述 |
| --- | --- |
| **组名** | 输入组的唯一名称。 |
| **成为**&#x200B;的子组 | 选择父组以组织层次结构。 您还可以在创建属性时创建组。 |

## 创建上下文属性 {#create-attribute}

1. 在&#x200B;**我的上下文属性**&#x200B;选项卡上，选择&#x200B;**新建上下文属性**。
1. 完成必填字段。
1. 选择&#x200B;**提交**。

### 属性字段 {#attribute-fields}

| 字段 | 描述 |
| --- | --- |
| **UI标签** | 输入受众条件中使用的显示名称。 |
| **ID** | 输入在应用程序请求中使用的唯一技术标识符。 |
| **上下文组** | 选择一个组，或创建一个新的内联组。 |
| **数据类型** | 选择与应用程序发送的数据匹配的类型。 |

| 数据类型 | 示例 |
| --- | --- |
| 字符串 | `gold` |
| 整数 | `42` |
| 布尔型 | `true` |
| 小数 | `9.99` |
| 日期 | `2026-07-17` |
| 版本 | `1.2.0` |

### 预定义值（可选） {#predefined-values}

使用预定义的值将属性限制为一组固定的值。 选择&#x200B;**添加预定义的值**。

| 字段 | 描述 |
| --- | --- |
| **UI标签** | 输入显示名称。 |
| **值** | 输入应用程序发送的技术值。 |

选择&#x200B;**保存**&#x200B;以应用更改。

## 故障排除 {#troubleshooting}

| 问题 | 解决方法 |
| --- | --- |
| **创建**&#x200B;已禁用 | 完成&#x200B;**组名**&#x200B;和&#x200B;**创建子组**。 |
| 无法提交属性 | 完成&#x200B;**ID**&#x200B;和&#x200B;**上下文组**。 |
| 组在下拉列表中不可见 | 刷新页面，或从属性表单中内联创建组。 |
| 未保存预定义的值 | 在提交属性之前，请在模式中选择&#x200B;**Save**。 |
