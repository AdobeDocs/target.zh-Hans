# 开始使用[!UICONTROL 体验定位] {#get-started-xt}

>[!BEGINSHADEBOX]

**在此页面上：**&#x200B;了解什么是&#x200B;**[!UICONTROL 体验定位]**，它如何适应个性化，以及场景如何定位具有不同体验的不同受众。

>[!ENDSHADEBOX]

[!UICONTROL 体验定位] (XT)根据一组营销人员定义的规则和条件向特定受众提供内容。 这对于定义规则非常有用，这些规则包括[地理定位](/help/main/c-target/c-audiences/c-target-rules/geo.md)，可将特定体验或内容定位到特定受众。 可以在单个活动中定义多个规则，以将不同的内容变体交付到不同的受众。

当访客查看您的网站时，[!UICONTROL 体验定位]会评估这些访客，以确定他们是否符合您设置的条件。 如果他们符合标准，则会进入活动，并且将显示为符合条件的受众设计的体验。

[!UICONTROL 体验定位]是走向个性化世界的第一步，通常从A/B测试开始。 营销人员运行A/B测试，并通过使用报表受众，发现不同的体验会与不同的受众产生共鸣。 通过[!UICONTROL 体验定位]，营销人员可以轻松使用该发现，并转为将内容长期定位到这些不同的受众区段。

## 情景：从A/B测试到体验定位 {#xt-scenario}

假定您的网站以户外设备为特色。 您的A/B测试报表显示您有三个体验，可与不同受众引起共鸣。 要应用此发现，您需要在主页上显示不同的主页图像来吸引每个受众，具体取决于访客的位置或喜好。 您希望向来自新泽西的访客展示徒步旅行图像，向来自夏威夷的访客展示冲浪图像，向喜欢骑自行车的受众展示第三个图像。

通过[!UICONTROL 体验定位]活动，您可以为这三个受众分别定位不同的主页图像。 以下视频介绍如何使用[!UICONTROL 体验定位]将A/B测试提升到新的级别。 它展示了如何：

* 使用三步引导式工作流配置[!UICONTROL 体验定位]活动。
* 通过创建定位到这两个州的体验以及定位到自行车爱好者的第三个体验，向不同地理区域的受众交付特定于位置的内容。
* 对三个体验重新排序，以确保向正确的受众交付正确的内容。
