# 报告和[!UICONTROL 自动定位] {#reporting-and-auto-target}

>[!BEGINSHADEBOX]

**在此页面上：**&#x200B;了解哪些报表可帮助您解释&#x200B;**[!UICONTROL 自动定位]**&#x200B;活动的结果。

>[!ENDSHADEBOX]

[!DNL Adobe Target]提供了三个报表来解释&#x200B;**[!UICONTROL 自动定位]**&#x200B;活动的结果：**[!UICONTROL 自动定位摘要]**&#x200B;报表、**[!UICONTROL 自动化区段]**&#x200B;报表和&#x200B;**[!UICONTROL 重要属性]**&#x200B;报表。 有关每个报表的详细信息，请参阅以下主题：

| 报表 | 详细信息 |
| --- | --- |
| [自动锁定摘要报表](/help/main/c-reports/personalization-reports/auto-target-summary-report.md) | **[!UICONTROL 自动定位摘要]**&#x200B;报表允许您在表格视图或图形视图中查看报表量度。<P>此报表允许您查看&#x200B;**[!UICONTROL 访问]**、**[!UICONTROL 转化率]**、**[!UICONTROL 平均提升度和置信区间]**&#x200B;以及&#x200B;**[!UICONTROL 置信度]**&#x200B;的量度。 |
| [自动化区段报表](/help/main/c-reports/c-personalization-insights-reports/automated-segments-report.md) | **[!UICONTROL 自动化区段]**&#x200B;报表显示不同访客对您的&#x200B;**[!UICONTROL 自动定位]**&#x200B;活动中的选件和体验做出的响应有何不同。 它显示[!DNL Target]的个性化模型定义的自动化区段如何响应活动中的选件和体验。 |
| [重要属性报表](/help/main/c-reports/c-personalization-insights-reports/important-attributes-report.md) | **[!UICONTROL 重要属性]**&#x200B;报表显示在不同的活动中，不同属性对于模型如何决定进行个性化的重要性如何。 它显示了影响模型的主要属性及其相对重要性。 |

有关一般报告信息，请参阅[报告](/help/main/c-reports/reports.md)。
